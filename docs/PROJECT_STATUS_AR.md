# حالة مشروع Mirage Leads Hunter

آخر تحديث: 2026-11-08

## المستودع
https://github.com/AhmedZawwed7/mirage-lead-generation2
الفرع: main

## المنفذ في نسخة الويب الحالية
- واجهة عربية RTL متجاوبة ولوحة مؤشرات مبنية على بيانات قاعدة البيانات الفعلية.
- بحث شركات عبر SerpAPI أو Google Programmable Search أو DDGS عند تهيئته.
- فحص صفحات المواقع العامة وصفحات التواصل، مع احترام robots.txt، وتحديد حجم الاستجابة، ومهلة الاتصال، وإبطاء الطلبات لكل نطاق.
- استخراج أرقام الهواتف والبريد الإلكتروني، وتقييم اكتمال بيانات العميل.
- حفظ دفعات البحث وسجل النتائج ومنع تكرار الهاتف/الموقع.
- CRM مبسط: حالات العميل، المسؤول، ملاحظات المتابعة، وروابط WhatsApp اليدوية.
- فريق مستخدمين بأدوار admin وmanager وresearcher وsales.
- صلاحيات API، وتحديد بيانات موظف المبيعات بالعملاء المسندين إليه، بما يشمل التصدير.
- تصدير CSV وExcel مع الحماية من Formula Injection.
- استقبال Leads داخليًا من مصادر Google Ads وMeta Ads وTikTok عبر webhook مشترك السر، مع تحقق الموافقة ومنع التكرار.
- حماية جلسات وCSRF وخصائص أمان HTTP وسجل تدقيق.
- اختبارات تلقائية عبر GitHub Actions.

## ما لم يكتمل / لا يجوز اعتباره متصلًا بعد
- OAuth وWebhooks الرسمية الموثقة من Google Ads وMeta Ads وTikTok.
- WhatsApp Business Cloud API وإرسال الرسائل المعتمد.
- SMTP حقيقي مع إعدادات حساب البريد.
- مهام بحث خلفية طويلة مع طابور، إيقاف، تقدم، وإعادة محاولة.
- PostgreSQL ومخطط ترحيل إنتاجي؛ النسخة الحالية تستخدم SQLite.
- سجل نشاط ومهام متابعة وتقويم ومواعيد تنبيه متكاملة.
- استيراد CSV/Excel متقدم ودمج سجلات متعددة المصادر.
- خريطة جغرافية وتقارير أداء وتحويلات متقدمة.
- نشر إنتاجي ومراقبة ونسخ احتياطي واستعادة واختبار E2E على بيئة مستضافة.

## بوابة الإصدار النهائي
لا يعلن الإصدار نهائيًا إلا بعد:
1. نجاح CI على آخر commit.
2. إعداد أسرار الإنتاج خارج GitHub.
3. اختبار البحث الحقيقي بمزود مفعل في بيئة تشغيل.
4. اختبار إنشاء مستخدمين وتوزيع العملاء وصلاحيات كل دور.
5. اختبار CSV وExcel وقيود الخصوصية.
6. اختبار استقبال webhooks من تطبيقات رسمية موثقة.
7. اختبار نشر واستعادة قاعدة البيانات والنسخ الاحتياطي.
8. اختبار قبول المستخدم UAT وإغلاق العيوب الحرجة.

## إعدادات التشغيل المطلوبة
- SECRET_KEY: قيمة عشوائية قوية وفريدة.
- MIRAGE_ADMIN_USER وMIRAGE_ADMIN_PASSWORD: بيانات مدير أولية قوية.
- COOKIE_SECURE=1 عند التشغيل خلف HTTPS.
- MIRAGE_DB: مسار قاعدة بيانات دائم وقابل للكتابة.
- SERPAPI_KEY أو GOOGLE_API_KEY مع GOOGLE_CX لتفعيل مزود بحث مدفوع.
- CAMPAIGN_WEBHOOK_TOKEN: سر عشوائي طويل لمسار استقبال الحملات.
