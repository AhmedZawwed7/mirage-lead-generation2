# حالة مشروع Mirage Leads Hunter

آخر تحديث: 2026-11-09

## النشر والبنية
- رابط الإنتاج: https://mirage-lead-generation2.vercel.app
- المستودع: https://github.com/AhmedZawwed7/mirage-lead-generation2
- Vercel مربوط بالفرع الرئيسي.
- قاعدة Neon PostgreSQL متصلة عبر `DATABASE_URL` / `POSTGRES_URL`.
- يوجد حقل `batch_id` لربط العميل بدفعة البحث.
- لا توجد مهمة حذف تلقائي للعملاء؛ السجلات تبقى محفوظة حتى حذفها إداريًا.

## الوظائف الموجودة في التطبيق
- لوحة Mirage موحدة وصفحات منفصلة للبحث والعملاء وWhatsApp والبريد والنشاط والإحصائيات والفريق.
- بحث DDGS لمحركات الويب بدون مفتاح API؛ Google Maps يتطلب `SERPAPI_KEY`.
- بحث حسب الدولة والمدينة واللغة والكلمات المفتاحية، مع توسيع استعلامات لبعض الأنشطة.
- فحص مواقع الويب العامة عبر 12 عاملًا متوازيًا، واحترام `robots.txt`، وفحص صفحات التواصل عند الحاجة.
- استخراج البريد والهاتف وروابط الهاتف وWhatsApp، مع تحقق دولي للأرقام عند توفر مكتبة phonenumbers.
- منع التكرار حسب الهاتف والبريد والموقع، وحفظ الدفعات وتصفية النتائج حسب الدفعة.
- CRM: حالات العملاء، إسناد موظفي المبيعات، ملاحظات، سجل نشاط، ومهام متابعة.
- تصدير CSV وExcel.
- SMTP test/send بعد توفير إعدادات الخادم.
- مرسل WhatsApp Web محلي عبر Playwright، يدعم QR، التأخير، الدفعات، الحد اليومي، المرفقات، الإيقاف، وتخطي optout.
- صلاحيات صفحات المرسل مقصورة على المدير ومدير المبيعات؛ موظف المبيعات يرى العملاء المسندين إليه.

## واجهة المستخدم والهوية
- تم توحيد نظام الألوان والتخطيط والتنقل في لوحة التحكم والصفحات الفرعية وتسجيل الدخول وإدارة الفريق.
- الواجهة عربية RTL.
- لا يوجد ملف شعار مستقل داخل ZIP الأصلي؛ كان يعتمد على رابط خارجي `logo.png`. لذلك يستخدم التطبيق حاليًا wordmark نصيًا باسم MIRAGE بدل علامة رسومية غير مؤكدة. يلزم ملف SVG/PNG الأصلي لاعتماد الشعار المطابق تمامًا.

## ما لا يزال يحتاج إعدادًا أو تنفيذًا واختبارًا
- تشغيل بحث حي فعلي بمزود DDGS في بيئة الإنتاج وقياس جودة النتائج.
- Google Maps لا يعمل قبل إدخال مفتاح SerpAPI صالح.
- اختبار Windows فعليًا على جهاز المستخدم ومسح QR؛ لا يمكن تشغيل Chrome على جهاز المستخدم من Vercel.
- WhatsApp Business Cloud API غير مربوط؛ الموجود هو WhatsApp Web المحلي.
- SMTP الحقيقي يحتاج بيانات الحساب وخادم البريد.
- Google Ads وMeta Ads وTikTok تحتاج OAuth وWebhooks الرسمية وموافقات الحسابات؛ الموجود حاليًا استقبال Webhook عام محمي.
- البحث الطويل يعمل داخل طلب HTTP متزامن؛ نظام Jobs/Queue مع تقدم حي وإيقاف واستئناف لم يكتمل.
- ترجمة كل عناصر الواجهة إلى الإنجليزية لم تكتمل.
- لم يُنفذ بعد اختبار End-to-End كامل يتضمن بحثًا حقيقيًا ثم حفظًا في Neon ثم إرسال WhatsApp فعليًا.

## طريقة تشغيل مرسل Windows
1. `vercel link`
2. `vercel env pull .env --environment=production`
3. تشغيل `start_windows.bat`
4. فتح `http://127.0.0.1:5000/whatsapp` وربط QR.

يجب إبقاء `.env` و`instance/wa_profile` و`uploads/` خارج GitHub.
