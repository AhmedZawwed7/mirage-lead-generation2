# قائمة تحقق الإصدار النهائي

## المنتج
- [ ] واجهة عربية RTL متجاوبة + واجهة إنجليزية.
- [ ] تسجيل دخول وصلاحيات مدير/مبيعات/باحث.
- [ ] بحث شركات حسب الدولة والمدينة والخدمات والكلمات المفتاحية.
- [ ] استخراج الهاتف والبريد والموقع مع حفظ المصدر.
- [ ] Batch مستقلة لكل عملية بحث وشريط تقدم.
- [ ] إزالة التكرار مع الاحتفاظ بالمصادر المتعددة.
- [ ] تقييم وترتيب العملاء.
- [ ] إسناد العملاء لفريق المبيعات.
- [ ] سجل مكالمات وملاحظات ومهام متابعة.
- [ ] استيراد CSV/Excel وتصدير النتائج المفلترة.
- [ ] تقارير أداء البحث والمبيعات.
- [ ] إعدادات SMTP واختبار الاتصال.
- [ ] تكاملات Ads وWhatsApp Cloud موثقة ومختبرة بعد توفير الاعتمادات.

## الجودة والأمن
- [ ] اختبارات وحدات وتكامل وقبول.
- [ ] فحص SSRF وCSRF وXSS وSQL injection.
- [ ] اختبار الصلاحيات بين المستخدمين.
- [ ] اختبار تحميل دفعات كبيرة وإيقاف المهمة.
- [ ] اختبار PostgreSQL واستعادة نسخة احتياطية.
- [ ] لا توجد أسرار أو قواعد بيانات تشغيلية في Git.
- [ ] فحص التبعيات والثغرات.
- [ ] اختبار فعلي من البداية للنهاية.

لا يُعلن الإصدار النهائي إلا بعد إغلاق جميع البنود الإلزامية وتوثيق البنود التي تحتاج اعتمادًا خارجيًا.
