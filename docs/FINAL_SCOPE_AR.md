# نطاق النسخة النهائية — Mirage Leads Hunter

## الهدف
منصة ويب عربية/إنجليزية للبحث عن الشركات وجمع بيانات التواصل العامة، وإدارة العملاء المحتملين وتوزيعهم على فريق المبيعات وقياس نتائج المتابعة.

## الوظائف الأساسية المطلوبة
1. البحث حسب الكلمات المفتاحية والخدمات والمدينة والدولة.
2. استهداف السعودية والإمارات افتراضيًا، مع دعم مصر والكويت وقطر والبحرين وعُمان والأردن والمغرب وتركيا وبريطانيا والولايات المتحدة.
3. جمع روابط المواقع العامة ثم زيارة الصفحات المسموح بها واستخراج أرقام الهاتف والبريد الإلكتروني واسم الشركة والموقع والمدينة.
4. إظهار مصدر كل معلومة وتاريخ جمعها، وعدم تجاوز robots.txt أو حدود المواقع.
5. تقييم العميل المحتمل وترتيبه وفق اكتمال البيانات وملاءمة النشاط.
6. حفظ نتائج كل عملية بحث في Batch مستقلة، مع إزالة التكرار دون فقد سجل المصدر.
7. البحث والتصفية حسب الدولة والمدينة والكلمة المفتاحية والتقييم والحالة والمسؤول.
8. استيراد وتصدير CSV وExcel.
9. عرض مواقع الشركات على الخريطة عند توفر إحداثيات أو عنوان قابل للتحويل.
10. توزيع العملاء على موظفي المبيعات، وتسجيل المكالمات والنتائج ومواعيد المتابعة.
11. تقارير أداء البحث والمبيعات والتحويلات.
12. إرسال البريد عبر SMTP بإعدادات يحددها مدير النظام.

## أدوار المستخدمين
- مدير النظام: المستخدمون والصلاحيات والإعدادات والتقارير.
- مدير المبيعات: توزيع العملاء ومراجعة أداء الفريق.
- موظف المبيعات: العملاء المسندون إليه وتحديث حالاتهم وتسجيل المتابعة.
- باحث: إنشاء عمليات البحث ومراجعة النتائج.

## حالات العميل
new → assigned → contacted → qualified → demo → won / lost / optout

## شروط القبول
- لا يُحفظ عميل بلا Batch ومصدر.
- لا يؤدي تكرار رقم الهاتف إلى إنشاء سجل مكرر داخل النظام.
- يحتفظ النظام بمصادر متعددة للعميل نفسه.
- لا يستطيع موظف المبيعات رؤية بيانات خارج صلاحياته.
- كل تغيير حالة أو إسناد يُسجل في سجل تدقيق.
- لا تُعرض عملية البحث على أنها مكتملة قبل انتهاء جمع النتائج وحفظها.
- التصدير يحترم الفلاتر والصلاحيات.
- يجب اختبار البحث والحفظ والتكرار والتوزيع والتصدير عمليًا قبل إعلان الإصدار النهائي.

## حدود التكاملات
- Google/Meta/TikTok Ads: استقبال العملاء يتطلب ربط OAuth/Webhooks رسمي وموافقات الحسابات؛ لا يتم ادعاء الاتصال دون مفاتيح واختبار حقيقي.
- WhatsApp: أتمتة WhatsApp Web ليست خدمة سحابية موثوقة. التكامل الإنتاجي المقصود هو WhatsApp Business Cloud API بعد توفير بيانات Meta.
- SMTP: يعمل فقط بعد إدخال بيانات خادم البريد والتحقق منها.
- الخرائط: تتطلب مزود Geocoding عند الحاجة إلى تحويل العناوين لإحداثيات.
