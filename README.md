# Mirage Leads Hunter

منصة Mirage للبحث عن الشركات واستخراج بيانات التواصل العامة وإدارة العملاء المحتملين.

## النسخة المنشورة
- رابط الإنتاج: https://mirage-lead-generation2.vercel.app
- المستودع: https://github.com/AhmedZawwed7/mirage-lead-generation2
- قاعدة البيانات: Neon PostgreSQL متصلة بمشروع Vercel.
- تُحفظ نتائج البحث في دفعات مستقلة، ولا توجد مهمة حذف تلقائي للعملاء.

## الوظائف الموجودة
- بحث متعدد الدول والمدن والكلمات المفتاحية عبر محركات DDGS بدون مفاتيح API.
- Google Maps عبر SerpAPI عند توفير `SERPAPI_KEY`.
- توسيع استعلامات البحث حسب النشاط والمدن واللغة.
- فحص 12 موقعًا بالتوازي، وزيارة صفحات التواصل عند الحاجة، واحترام `robots.txt`.
- استخراج الهاتف والبريد والموقع، والتحقق من أرقام الهواتف، ومنع التكرار.
- ربط العملاء بدفعات البحث وعرض نتائج كل دفعة مع انتقال مباشر إلى صفحة WhatsApp.
- CRM: حالات العملاء، الملاحظات، المسؤولون، الأنشطة، ومهام المتابعة.
- تصدير CSV وExcel، وإرسال البريد عبر SMTP بعد إدخال إعداداته.
- مرسل WhatsApp Web محلي على Windows باستخدام Chrome/Chromium وPlaywright.

## تشغيل WhatsApp على Windows
1. ثبّت Python 3.11+ وNode.js وVercel CLI.
2. نفّذ `vercel link` من مجلد المشروع.
3. اسحب اتصال Neon إلى ملف محلي خاص: `vercel env pull .env --environment=production`.
4. شغّل `start_windows.bat`.
5. افتح `http://127.0.0.1:5000/whatsapp` واضغط زر ربط WhatsApp / QR، ثم امسح الرمز من الهاتف.

يستخدم المرسل قاعدة Neon نفسها التي تحفظ نتائج البحث، ويحفظ جلسة WhatsApp على جهاز Windows فقط. لا ترفع `.env` أو `instance/wa_profile` أو `uploads/` إلى GitHub.

## ما يحتاج إعدادًا أو استكمالًا قبل اعتباره تكاملًا إنتاجيًا
- Google Maps يحتاج مفتاح SerpAPI صالحًا.
- WhatsApp Web يعمل محليًا على Windows فقط؛ WhatsApp Business Cloud API غير مربوط بعد.
- SMTP يحتاج بيانات خادم البريد وكلمة مرور تطبيق.
- Google Ads وMeta Ads وTikTok تستقبل Leads عبر Webhook محمي، لكن OAuth والربط الرسمي لكل منصة يحتاج بيانات واعتمادات الحسابات.
- البحث الطويل ما زال طلبًا متزامنًا؛ طابور خلفي مع تقدم حي وإيقاف/استئناف يحتاج مرحلة مستقلة.
- الواجهة الحالية عربية RTL؛ دعم الإنجليزية في استعلامات البحث موجود، لكن ترجمة كل عناصر الواجهة لم تكتمل.
- ملف الشعار الأصلي لم يكن مرفقًا داخل ZIP؛ الواجهة تستخدم حاليًا wordmark نصيًا ثابتًا بدل شعار غير موثوق.

## الأمان
لا ترفع ملفات `.env` أو كلمات المرور أو مفاتيح API أو قواعد البيانات أو ملفات جلسة WhatsApp أو صادرات العملاء إلى GitHub.
